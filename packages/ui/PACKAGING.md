# 打包回归

```sh
pnpm build
pnpm test:package
```

JS 保留模块边界并压缩，保留客户端边界、纯调用标记和许可证注释。Context 统一惰性创建；主库与 Game 共用内部模块。CSS 通过 Tailwind 官方编译 API 构建。

检查使用真实 npm tarball，覆盖公开导出、相对引用、外部 TypeScript 消费、Context 身份、样式和图片。六种用量分别比较公共入口、直接组件模块和重新合并的单文件版。公共入口必须保留相同的内部模块；体积允许 raw 多 256 B、brotli 多 128 B，以容纳变量改名和排列差异。
