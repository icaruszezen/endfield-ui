# 动效补全计划

给控件补上缺的动效，并把已有的几处调顺。分六个模块，先易后难；**一步一个提交，做完一步勾一步**，不跨步、不合并。

- 依据：[动效](design/foundations/motion.md)。这里补的都是规范里没有逐条写到的，来源等级一律标"推断"。
- 盘点日期：2026-10-10。盘点方法是把 `packages/ui/src/components` 下每个目录用到的过渡和动画类列出来，再逐个看状态变化的那一行是怎么写的。
- 现状：悬停换色（200ms）基本都有；浮层有淡入；折叠面板、抽屉、开关、进度有过渡。缺的是三类——**状态记号硬切出现、内容增删硬切、选中指示在项间瞬移**。

## 约定

### "舒适"在这里指什么

不改规范的五条原则（短、硬、有因果、戏剧性留给入场、可以关），只在里面补：

- **该有过渡的地方有过渡。** 状态变了而画面硬切，是这次主要要消掉的。
- **进出不对称。** 进入用 `duration-base`（300ms），退出用 `duration-fast`（200ms）：来的时候看得清从哪来，走的时候不挡路。
- **有方向。** 浮层从触发它的那一侧来，位移 4px；大面积的 8px。位移只是提示方向，不是滑行。
- **错开要克制。** 逐项入场每步错开 50 – 100ms，最多错开前五六项，后面的一起到。
- **跟手的不加过渡。** 拖动、滑动手势进行中，位置必须贴着手指；过渡只给"跳过去"的那种变化。

仍然不做：过冲和回弹、悬停放大或上浮、加重阴影、持续的漂浮与呼吸、超过 600ms 的过渡。

### 缓动（已定：守着现有三条）

规范写明官网没有用任何自定义贝塞尔曲线（实测）。两种做法：

1. 守着现有三条（`ease`、`ease-in-out`、`ease-out`），只补过渡、加进出不对称和方向位移。
2. 加一条不带过冲的减速曲线，手感更顺，但要先改规范里那一条。

模块一到三按第 1 种做；模块三做完后回看了一次（3.6），**定的是第 1 种，不加**。后面的模块照这个做，不用再问。

### 每一步的固定流程

1. **先改规范**：[动效](design/foundations/motion.md) 和这个控件所在的那篇组件文档，写清楚"什么变了、怎么动、多久"，标来源等级。
2. **实现**：只用 [theme.css](../packages/ui/src/styles/theme.css) 里的时长与缓动令牌；能用 `transform` / `opacity` 就不动布局属性。
3. **自查三件事**：
   - 系统开了"减少动态效果"时停在终态，不停在透明或屏幕外；
   - 状态不只靠动效表达（动效关掉之后还分得清）；
   - 高对比模式和触屏上没有多出来的东西。
4. **测试**：单元测试；需要时加一个能看清动效的 story。
5. **浏览器实测**：提交前跑受影响的检查文件和 `motion.check.ts`；整套（原速、`CPU_THROTTLE=2` 各一遍）放在推送前跑。
   - 检查默认开着"减少动态效果"，过渡被压到 0.01ms，所以旧断言多数不受影响；"状态一变就读样式"的仍然会读到过渡的起点，改用 `page.settled()`（0.2 加的）等它走完。
   - 新的动效断言写在 `motion.check.ts` 里（它会临时关掉"减少动态效果"）：断言**声明了什么过渡**（读计算样式）和**走完之后的终态**，不去赌过渡正跑到一半的那一刻。
6. `pnpm format:check` → `pnpm lint` → `pnpm typecheck` → `pnpm test` → `pnpm build`。
7. **提交**，把这一步勾掉。**推送可以攒两三步一起**：推之前跑第 5 条说的整套实测，推完等 Actions 三个 job 都过、看一眼在线站点，再做下一组。
8. **人工验证**：做完之后由人在预览站上亲手操作看一遍，看过的在那一步的标题后面标上"已人工验证"和日期。勾只代表做完并且自动断言过了；没有这个标记的，动起来好不好看还没有人看过。

## 模块四：展开与增删（中）

做的顺序是 4.4 → 4.1 → 4.2 → 4.3 → 4.5 → 4.6：4.1 的收起、4.2 的消失、4.5 都要先有 4.4。编号不动。

- 2026-10-11　模块五做的过程中定下来的实测写法：
  - 点一下、读指示身上的过渡、把它停住，放在页面里的同一步做（`motion.check.ts` 的 `pickItem`）：分成几次往返，页面慢的时候 200ms 的过渡可能已经走完。上一次停住的在下一次点之前先放开——目标没变的那几条不会被新的过渡换掉。
  - "第一次到位不过渡"：把容器藏起来再放出来，位置是重新量的，看这一回指示身上有没有过渡。
  - 要一项"变高了"就直接把它撑高，不靠压窄了让中文标题折行：CI 上没有中文字体，字比本机窄，折不折行说不准（5.3 的实测第一版因此在 CI 上红了一次）。
  - 推送前的整套实测里偶发了一条和这一组无关的：下拉选择"开着的时候页面不滚动"读早了——基元把锁滚动排在零毫秒的定时器里。改成等它锁上，单独一个提交。
