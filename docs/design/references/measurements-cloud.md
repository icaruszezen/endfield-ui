# 云游戏页实测数据

本页是 [云游戏页](../surfaces/cloud.md) 引用的**原始数据**。所有数值来自 2026-10-24 在浏览器中读取《云·终末地》官网的计算样式与样式表规则；没有转存官方的样式文件、图片或字体。

- 页面：[https://endfield.hypergryph.com/cloud](https://endfield.hypergryph.com/cloud)，挂在官网域名下；各视图的入口见 [官方来源](official-sources.md)。
- 测量：2026-10-24，在浏览器里读计算样式、元素几何和样式表规则。样式表是跨源的，读不到 cssRules，是把文本取回来自己解析的；仓库里不存任何官方文件。每份原始记录都另做过一遍独立复测，本页取复测更正后的值。
- 视口：1440×810（主测，`html` 16px）、1024×768；375×812 量了两种——桌面版载入后直接缩窗，和换成移动平台（Android UA）重新载入。
- 样式表文件名 `index.83cf05.css`。类名是 6 位哈希，每次构建都会变，下文统一去掉哈希，按角色称呼部件；图片也去掉文件名里的哈希，只记文件名和原图尺寸。
- 未登录的视图在全新的无头浏览器 profile 里量；登录后的视图在维护者自己已登录的会话里量，UID、头像、时长、余额、记录一律不记，商城价格也不记。
- 来源标记：**规则** = 样式表原文；**计算** = 计算样式与实测几何；**观察** = 看得到但没有可读数值（图片像素、SVG 内容）；**脚本** = 读页面脚本得出的行为或常量。没标的默认是规则加计算。
- 官网首页的数据在 [官网实测数据](measurements.md)。两边是两套构建，根字号、字体、颜色都不同，数值不通用。
- 官网会改版。数值过期时以重新测量为准，并更新本页日期。

## 1. 尺寸基准

页面脚本把根字号写进 `html` 元素的内联样式：

| 平台 | `html` 字号 | 说明 |
| --- | --- | --- |
| 桌面，宽 1180 – 2560px | 16px | 固定，不随视口缩放；高度不参与 |
| 桌面，宽不到 1180 或超过 2560 | `16 × 宽 / 1920`（即宽 / 120） | 整页等比缩放，不重排 |
| 移动平台 | `16 × min(1, 短边 / 390)` | 竖屏按宽、横屏按高算，上限 16px |

- 写法：先写目标值 a，再读一次计算值 l，不相等就改写成 a²/l，抵消浏览器的最小字号限制；Android 上的 QQ 浏览器和鸿蒙 UA 跳过这一步。（脚本）
- 平台（`body` 的 `data-platform`）只在模块载入时判定一次：平板类（iPad、不带 Mobile 的 Android、粗指针无悬停等）判成 mobile；其余桌面 UA 一律 desktop，非桌面 UA 短边 ≤600 判成 mobile。改窗口大小不会换平台，要重新载入。（脚本）
- 移动平台进游戏、开公告时会强制横屏：`body` 宽高互换并转 90°（`data-rotate="1"`），字号按转过之后的宽高算。（脚本）
- 样式表里没有按宽度写的桌面断点，布局断点在脚本里（1180 / 2560），移动端规则写成"平台属性 + 方向"。唯一一条和 16px 区间对齐的媒体查询是未登录宣传图的尺寸（8.4）。

验证（每次改尺寸后派发 resize 再读）：

| 视口 | 平台 | `html` 字号 |
| --- | --- | --- |
| 1440×810、1440×400、1920×300、1920×2400、2560×1440 | 桌面 | 16px |
| 1180×810 / 1179×810 | 桌面 | 16px / 9.825px |
| 1024×768 | 桌面 | 8.53334px |
| 2561×1080 / 3840×2160 | 桌面 | 21.3416px（内联值只留 4 位小数）/ 32px |
| 375×812（桌面版缩窗） | 桌面 | 3.125px |
| 375×812 / 414×896 | 移动 | 15.3846px / 16px |
| 360×740、740×360 / 320×568 | 移动 | 14.7693px / 13.1282px |

下文的 rem 在 1180 – 2560 宽时就是 16px，括号里的像素值都按 1440×810 写。

几处另有尺度：

- **"更多"视图**是一块 2560px 宽的设计画布，用 `transform: scale()` 整体缩放：`scale = (容器宽 − 侧栏宽) / 2560`，桌面上侧栏宽变量是 0，所以 1440 宽时 0.5625、1024 宽时 0.4；画布高 = 可视高 / scale。它的规则全用 px，下文记作"设计 px"，屏幕 px = 设计 px × scale。画布里的页脚再用 `zoom` 反缩放回原尺寸。（脚本）
- **下载弹窗**按 108.5 × 53.5rem 排版（1736 × 856 设计 px）后整体缩放，桌面上约占视口宽的 1736 / 2560 = 67.8%（8.10）。
- **公告面板**是另一个站点的内嵌页，根字号自己算（8.12）；**商城面板**内联写了 `font-size: 视口宽 / 1194 × 16px`，只影响继承文字（9.4）；**页脚**来自鹰角网页 SDK，全用固定 px（8.7）；**鹰角账号 SDK** 不用 rem，用自己的 `--base-em-size` 字号档（11.3）；支付 SDK 用 `--pay-sdk-size`（9.4）。

## 2. 字体

- 一个字族名只对应一个字重：换字重靠换字族名，不靠 `font-weight` 选面。字阶里的 `btn2_w600` 是 CloudGameRegular 配 600，靠浏览器合成加粗，用户中心下拉的条目就是它（9.2）。
- 字族名和文件名都直接写着 HarmonyOS Sans SC。这支持 [官网首页](measurements.md) "改了名的中文字体是 HarmonyOS Sans SC"的推断，但不能证明：两边是不同的构建，也没做字形比对。
- 页面没有给 `html`、`body`、`#root` 设字体。没写字体的元素继承浏览器默认字体（测量机上是 Noto Sans SC），例如顶栏容器、"更多"侧栏下载按钮的本体、节点选择的表头（9.5）。另有系统字体栈：-apple-system 一组 4 次（其中有"更多"加载层的百分比），PingFang 一组 1 次（游戏内跑马灯）。
- SDK 自带字体：页脚用 SDK_Sans（8.7），账号 SDK 弹窗用 sans-serif 和 Arial（11.3），支付 SDK 用 "HG Source Han Sans"（9.4）。

## 11. 鹰角账号 SDK 弹窗

这是鹰角各游戏共用的账号组件（登录、实名、协议更新等），不属于终末地站点自己的设计；这里只记它在 /cloud 上的样子，供对照。

尺寸都写作 E(n)：`E(n) = calc(var(--base-em-size, 16px) * n / 16)`。1440×810 下 E(n) = 0.8n px，375 宽和 1920×1080 下 E(n) = n px（11.3）。

### 11.1 版本与皮肤

- 版本：账号 SDK 3.5.0，/cloud 与官网首页相同；外壳是网页 SDK 3.0.3（页脚和 SDK_Sans 字体来自它）。两份灰度配置里的稳定版也是这两个。
- 样式全部是 SDK 运行时插入的内联样式，登录相关的那部分在打开登录框时才懒加载；页面自己的样式表里没有。
- 皮肤模块默认值是 "ak"，`set()` 只认 "ef" 和 "ak"，别的值一律回落 ak。皮肤类挂在每个层容器自己身上，不在祖先上。（脚本）
- 载入时 SDK 先插一个空的遮罩节点，调登录时再插一个装层的（或复用空的），关掉后都留在 `body` 里。

| 皮肤 | 品牌色 | 怎么出现 |
| --- | --- | --- |
| 默认（无皮肤） | `#CBFF40` | 3.5.0 里正常调用拿不到；变量还留在样式表里（深色卡片配荧光绿） |
| ak（明日方舟） | `#0098DC` | 官网首页载入后没有设过皮肤，SDK 停在 ak；直接调 `User.UI.login({})` 渲染出来的也是它。[官网实测数据](measurements.md) 3.4 记的"品牌蓝"就是这个 |

### 11.3 字号档与字体

SDK 不用 rem，页面的根字号对它没有影响。弹窗根上按媒体查询给 `--base-em-size`：

| 条件 | 基准 | 备注 |
| --- | --- | --- |
| 宽 600 – 1917px，高 ≥431 | 12.8px | 1440×810 实测 |
| 宽 1918 – 2557px，高 ≥431 | 16px | 1920×1080 落在这档（推算） |
| 宽 2558 – 3837px / ≥3838px，高 ≥431 | 19.2px / 21.6px | |
| 宽 ≥600px，高 ≤430 | 10px | 矮屏 |
| 宽 ≤600px | 16px | 375 实测 |

- 加载转圈的容器挂在遮罩下、不在弹窗根里，取不到基准，E(n) 走回退值 16px：任何视口都是 80 × 80px、圆角 4px。

- 支付 SDK 的 `--pay-sdk-size` 见 9.4。

## 12. 没有量到的东西

- 烧在图里的文字（首页宣传块、下载弹窗标题与"扫码下载"、"更多"的块状大字和微缩字、公告 NEW 角标）只有位置和像素颜色，字体、字号、字形内容都读不到。图里的颜色、条纹角度和周期是读像素的近似值，没有逐像素还原（SDK 的 ef 装饰图只做了像素统计）。
- 真悬停量过的只有首页的导航项、页签、胶囊按钮，用户中心条目的字色，账号卡的提示图标与气泡，以及账号 SDK 的按钮、链接、输入行和关闭钮；下载弹窗、"更多"侧栏、公告页、商城的悬停与按下只读了规则。后台标签页不出帧，"更多"的入场动画也没看到实际画面，时长、延迟、缓动全部来自规则。
- 手机横屏的首页、"更多"、商城、分享浮层只有规则；强制横屏下的实际字号和 SDK 字号档没量。移动端只在 Android 模拟（宽 768 以下）下测过，iPhone、iPad、鸿蒙 UA 在内置浏览器里没测；Android UA 重新载入后页脚是空的，无头 Edge 换 iPhone UA 时页脚正常，原因没查清。
- 设了最小字号的浏览器上字号校正会生效，排版会和表里不同。
- 浏览器提示条"正常版本的 Edge 不出现"是按兼容表推的；移动版和应用内浏览器版没有出现过。
- 全局提示组件没有在页面上触发过：复制链接、添加到桌面的结果提示和公告页底部的提示都没看到样式。"更多"第 2 – 4 节的视频只读了文件规格，播放行为没有实测。
- 启动加载层真实出现时的计算值：复测时登录状态确认得很快，尺寸是把同类名的节点临时挂上去量的。
- CDKEY 兑换页（跨源）、账号与安全（会离开本页）、退出登录（会改账号状态）都没有打开；未登录时点"用户中心"只在手机模拟下点过一次，弹出的是账号 SDK 登录框，没有量。
- 登录态只拿到过一次：账号卡在 1024 宽和移动端都没有计算值；时长说明弹窗是在未登录页面上用同样的参数调出来的。收银台、排队面板、节点选择、悬浮球菜单、游戏内提示全部没有渲染，只有规则和探针。
- 账号 SDK：设备验证、实名、挽留、未成年、防沉迷、扫码视图、密码登录都没渲染；勾选框和二维码角标在 ef 下没有真悬停；带授权参数的登录路径和 1920×1080 没量。
- 公告页什么时候切暗色主题、它 `body` 上的自定义光标为什么没生效，都没查。
