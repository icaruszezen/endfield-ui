# 官方来源索引

写规范时看过、或建议后续继续观察的官方渠道。本仓库不转存其中任何画面，文档里需要看原图的地方都链到这里。

## 来源等级

全套文档用四个等级标注每条规则的依据：

| 等级 | 含义 | 可复核性 |
| --- | --- | --- |
| **实测** | 从官网的计算样式或样式表规则里直接读到的数值 | 任何人打开官网开发者工具都能复核，原始数据见 [measurements.md](measurements.md) |
| **观察** | 打开官方公开页面看到的现象，没有可读的数值 | 可复核，但受版本更新影响 |
| **社区** | 开源项目作者的取值或观察，本仓库没有独立验证 | 出处见 [open-source-projects.md](open-source-projects.md) |
| **推断** | 本文档根据上述材料做出的设计建议 | 不是事实，可以推翻 |

## 观察游戏界面的建议方法

游戏界面是这套文档里证据最薄的部分，补充时建议：

1. **按界面家族采样**，不要按截图数量。每个家族（HUD、地图、角色、仓库、技能树、数据、通讯）挑一两张信息完整的画面。
2. **只记文字观察**：结构、颜色角色、形状、状态变化。取色时记下取样位置。
3. **区分系统与主题**：角色、活动、地区的主题色不是系统色；环境光不是界面色。
4. **两处以上才算规律**：只在一个界面出现的做法写进对应家族，不写进基础规范。
5. 把结论写进 [game-ui.md](../surfaces/game-ui.md)，并把来源等级从"社区"改成"观察"，注明版本与日期。
