# 官网实测数据

本页是其他文档引用的**原始数据**。所有数值来自 2026-10-08 在浏览器中读取 [终末地官网](https://endfield.hypergryph.com/) 的计算样式与样式表规则；没有转存官方的样式文件、图片或字体。

- 测量视口：横屏 1024×768 与 1440×810，竖屏 375×812。
- 官网会随版本更新改版。数值过期时以重新测量为准，并更新本页日期。
- 样式表里的类名带构建哈希（如 `Button_button__njqVS`），下文统一去掉哈希，只保留组件名。

## 1. 尺寸基准

官网全站用视口比例缩放的 `rem`：

| 方向 | `html` 字号 | 换算 |
| --- | --- | --- |
| 横屏 | `100vw / 160` | 设计稿 1920px 宽时 `1rem = 12px` |
| 竖屏 | `100vw / 67.5` | 设计稿 1080px 宽时 `1rem = 16px` |

验证：1024px 宽时 `html` 字号为 6.4px，1440px 宽时为 9px，375px 宽竖屏时为 5.556px。

下文的 `rem` 都是这种"流式 rem"，括号里的像素值按 1920px 设计稿换算。

## 7. 动效

样式表里的过渡时长统计：

| 时长 | 规则数 |
| --- | --- |
| `0.3s` | 119 |
| `0.2s` | 63 |
| `0.4s` | 8 |
| `0.5s` / `0.6s` | 各 3 |
| `0.05s` / `1s` / `1.4s` | 各 1 |

显式声明的缓动只有 `ease-in-out`（15）、`ease-out`（6）、`linear`（3），其余用浏览器默认的 `ease`；没有出现自定义 `cubic-bezier`。

关键帧：

| 名称 | 内容 |
| --- | --- |
| `flashing` | `opacity`：0 → .5（10%）→ 0（11%）→ .5（20%）→ 0（21%）→ .5（40%）→ 0（41%）→ 1（100%），三次短促闪烁后点亮 |
| `scrollTipMove` | `translateY(0)` 且透明 → 60% 时不透明 → 80% 时下移 1.5rem 且透明 → 复位，循环 |
| `scrollBreathing` | `scale(1)` → `scale(1.2)` → `scale(1)` |
| `carousel` | `translateX(0)` → 80% 时 `translateX(-50%)` → 停留到 100%，跑马灯 |
| `rotate` | 匀速旋转一周 |
| `fadeIn`（加载页） | `scaleX(0)` → `scaleX(1)` |

## 10. 没有量到的东西

- 官网的装饰线稿、纹理、注册色条都是图片资源，没有可读的 CSS 值；文档里涉及它们的颜色与尺寸都是目测。
- 字体的字形特征没有做比对，中文字体的结论是推断。
- 游戏客户端内的任何数值都不在本页范围内；相关内容见 [游戏界面](../surfaces/game-ui.md)，其来源等级是"社区"。
